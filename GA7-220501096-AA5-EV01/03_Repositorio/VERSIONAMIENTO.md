# Versionamiento

El proyecto se preparo para control de versiones con Git y publicacion en el repositorio SAAAF.

Comandos principales:

```bash
git init
git add .
git commit -m "Implementa servicio de registro e inicio de sesion - GA7-AA5-EV01"
git branch -M principal
git remote add origin https://github.com/Brayan-Giraldo/SAAAF.git
git push -u origin principal
```

Para el repositorio existente, se recomienda subir esta evidencia dentro de la carpeta:

`GA7-220501096-AA5-EV01/`
