# Subida al repositorio SAAAF

Repositorio: https://github.com/Brayan-Giraldo/SAAAF

## Desde la interfaz web de GitHub

1. Entrar al repositorio SAAAF.
2. Seleccionar **Add file > Upload files**.
3. Subir el contenido de `01_Proyecto_Frontend_SAAAF` en una carpeta del repositorio llamada, por ejemplo, `frontend`.
4. Subir también la documentación de la evidencia en `evidencias/GA7-220501096-AA4-EV03`.
5. Usar como mensaje de commit: `Implementa componente front-end SAAAF - GA7-AA4-EV03`.
6. Confirmar con **Commit changes**.
7. Abrir el repositorio en una ventana de incógnito o compartir acceso con el instructor para comprobar que puede consultarlo.
