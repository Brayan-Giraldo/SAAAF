# Historial de fuentes

El archivo `saaaf_fuentes.bundle` conserva dos commits locales reales de la base recibida y de la revisión. No es un enlace remoto ni acredita una publicación en GitHub. La identidad de los commits indica preparación asistida.

Desde esta carpeta, con Git instalado:

```sh
git clone saaaf_fuentes.bundle SAAAF_fuentes
cd SAAAF_fuentes
git log --oneline
```

El bundle conserva fuentes y manuales. El informe Word/PDF, las capturas y los resultados de pruebas se entregan en las demás carpetas del ZIP; no se atribuyen al historial del bundle. El material original completo se conserva en `05_Fuentes_Originales`.
