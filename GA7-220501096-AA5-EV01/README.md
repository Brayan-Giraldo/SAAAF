## Diseño y desarrollo de servicios web - caso

### Proyecto
SAAAF - Sistema de Administración de Activos Fijos.

### Aprendiz
Brayan Giraldo García

### Programa
Análisis y Desarrollo de Software.

### Descripción
Esta evidencia implementa un servicio web para el registro de usuarios y el inicio de sesión dentro del proyecto SAAAF.

### Funcionalidades implementadas
- Registro de usuarios.
- Inicio de sesión.
- Validación de campos obligatorios.
- Validación de usuarios duplicados.
- Validación de credenciales.
- Manejo de respuestas de autenticación.
- Protección de contraseñas mediante hash.
- Código documentado y versionado con Git.

### Endpoints principales
- POST /api/auth/register
- POST /api/auth/login
- GET /api/health
